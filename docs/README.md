## Como manter estes guias

Descreva o comportamento do código atual. Tarefas e correções propostas pertencem às issues; não documente uma correção pendente como proteção já entregue. Os guias de uso não dependem de notas privadas, capturas do site ou dados de conta.

Esta pasta também pode conter notas locais antigas do mantenedor, ignoradas pelo Git. Somente os documentos enumerados em `scripts/documentation-files.txt` são públicos e entram nos pacotes. Não adicione capturas, respostas autenticadas ou relatórios de conta à lista.

As regras de contribuição e os invariantes do projeto ficam em [AGENTS.md](../AGENTS.md); o histórico de versões fica em [CHANGELOG.md](../CHANGELOG.md).
